# Vision Pro 真机核对清单

浏览器回归覆盖按钮、布局、键盘、音频和模拟 XR 状态；这一份记录**仍需真实设备确认**的部分。浏览器检查不代表真实设备能力可用。
逐项打勾，异常记一行现象，方便回头定位。

## 0. 准备

- [ ] 用 **Safari** 打开 `https://onebirdrocks.github.io/3d-examples/`（WebXR 必须 HTTPS）
- [ ] 右上角选「沉浸模式」，进入 `月夜庭院`（或任意场景）
- [ ] 头显与 Mac 同网；系统设置里允许 Safari 使用运动与方向权限
- [ ] 确认头显里**没有**「浏览器不受支持」提示，会话能真正进入 `immersive-vr`

---

## 1. 渲染与性能

- [ ] 进入沉浸后画面**立刻出现**，不是黑屏
- [ ] 转头环视一周，画面没有接缝、没有左右眼错位（重影）
- [ ] 快速转头不撕裂、不闪黑；画面稳定不闪烁
- [ ] 帧率主观判断流畅（对着灯看有明显频闪说明帧率低）
- [ ] 后处理场景（如霓虹雨夜）在 XR 下没有「只渲单目再复制」的糊化

## 2. 空间音频

- [ ] 进入场景后声音正常响起（若被自动播放策略拦住，点一次音效开关）
- [ ] 转头时**声音方位跟着变**（炉火声从炉膛方向来、溪水声从溪流方向来）
- [ ] 被物体遮挡时，高频变闷（低通遮挡生效）
- [ ] 空间音源有轻微混响尾巴，不像贴在耳朵上
- [ ] 声音左右声道不偏、不倒置

## 3. 手部骨架与捏合

- [ ] 抬起手，**能看到手指关节与骨骼**被追踪出来
- [ ] 五指张合时骨架跟着变形，没有断指或整体漂移
- [ ] 捏合（拇指+食指）能选中场景里的可交互对象（推拉障子门 / 按琴键 / 抓控制环）
- [ ] 捏住后能拖动，松手后回弹或停在合理位置
- [ ] 两只手同时出现，互不串位

## 4. AR 放置（另用支持 immersive-ar / hit-test 的设备）

- [ ] Vision Pro Safari 不支持真实空间放置时，入口保持禁用且页面说明原因，沉浸 VR 入口不受影响
- [ ] 切到「放到真实空间」
- [ ] 屏幕上出现贴合真实地面的指示环，会跟着移动设备平移
- [ ] 命中有效表面时圆环出现；离开可用表面时圆环消失
- [ ] 捏合即放置，场景内容**真正落在真实地面上**，比例合理
- [ ] 环视一周，场景内容是固定在房间里的，不会跟着头转

## 5. 持久锚点（仅在 AR 设备提供对应接口时）

- [ ] 未提供持久锚点接口时，仍可手动放置，不宣称下次打开后位置保留
- [ ] 放置一次场景后**退出沉浸模式**，再重新进入
- [ ] 场景内容**仍在原来的位置**（没被重新随机摆放）
- [ ] 重启浏览器 / 重启头显后再试一次，位置仍然保留

## 6. 命中表面贴合（兼容 AR 设备）

- [ ] 在桌面上放置场景，内容**贴合桌面**而不是悬空或穿模
- [ ] 在墙面前放置，内容贴合墙面
- [ ] 放置朝向与实际命中表面一致，不被其他表面的朝向覆盖

## 7. 分层混音与环境预设（本次新增）

- [ ] 场景页右侧打开混音面板，能看到 **5 路推子**：风声 / 水声 / 虫鸣 / 乐声 / 雨声
- [ ] 单独拖动每一路，声音**只有那一路**变化，其余不变
- [ ] 切到「雨夜」：画面立刻变（云厚、月暗、雾浓、水面起雨点、天上落雨丝）
- [ ] 切到「雨夜」：**雨声图层**明显加入，风声变大、虫鸣几乎消失、乐声压低
- [ ] 切回「晴夜」：雨声消失，雨丝停下，月亮重新变亮
- [ ] 在雨夜模式下手动拖动雨声推子，音量跟着变

## 8. 舒适度

- [ ] 场景内容的高度合适，站着看不用低头太久
- [ ] 环视全周不会看到明显的「场景边缘」或穿帮的接缝
- [ ] 长时间观看眼睛不累（曝光没有跳变）

---

## 已知未验项

- **光估计（light-estimation）没有接入**。会话里请求了这个能力，但 three 的
  `XREstimatedLight` 依赖非标准调用，Web 端能否拿到数据要真机确认后再决定投入。
  所以目前场景光照**不会**跟随你房间的真实亮度变化。
- 上述第 1~6 项此前只做过代码级验证，**没有真机实测**。这次逐项核对后如果有问题，
  按「现象 + 场景 id + 设备型号 + visionOS 版本」的格式记下来再回改。
